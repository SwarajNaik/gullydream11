# CLAUDE.md

## Project Overview

GullyDream11 is a web-based fantasy cricket platform that replicates the Dream11 experience. Players create virtual cricket teams from real-world players, join contests/tournaments created by admins, and earn points based on real-life player performance. The platform is designed for private/community use — payments happen offline (physically), and the system only tracks winnings, entry fees owed, and balances.

## Tech Stack

- **Frontend**: Next.js 14, React 18, TypeScript, Tailwind CSS, shadcn/ui, Zustand, React Query
- **Backend**: FastAPI, Python 3.11+, SQLModel, Alembic, UV package manager
- **Database**: PostgreSQL 16 (asyncpg), Redis 7 (cache, leaderboard, real-time data)
- **Auth**: Email/Password + JWT (HS256)

## Agents

Use the **backend** agent for all Python/FastAPI/DB work. Use the **frontend** agent for all Next.js/React/Tailwind work. Each agent encodes the mandatory coding patterns for its domain.

## Development Commands

```bash
# Start services
./scripts/run-backend.sh          # Backend (port 8000) + Docker services
./scripts/run-frontend.sh         # Frontend (port 3000)

# Backend
uv sync                           # Install deps
uv run pytest                     # Tests
uv run ruff check src --fix       # Lint
uv run ruff format src            # Format

# Frontend
cd frontend && npm run check      # Lint + type-check
npm run build                     # Production build

# Database
./scripts/run-db-migration.sh migrate          # Apply migrations
./scripts/run-db-migration.sh create 'message' # New migration

# OpenAPI pipeline (run after any backend schema/route change)
npm run generate-spec             # Export ./openapi.json from FastAPI
npm run generate-types            # Spec + regenerate frontend/src/lib/api/types.ts
```

Required flow: change SQLModel/Pydantic model -> export spec -> regenerate types -> update hooks -> commit together.

## Architecture

```
src/                              # Backend
├── app.py                        # FastAPI app, middleware, probes
├── config.py                     # Settings from environment variables
├── api/routes/                   # Thin controllers (Depends auth, response_model)
├── api/schemas/                  # Pydantic v2 models (APIResponse[T] envelope)
├── api/services/                 # Business logic (no HTTP concerns)
├── api/dependencies/             # DI: auth, DB session, permissions
└── db/models/                    # SQLModel + Alembic migrations

frontend/src/                     # Frontend
├── app/                          # Next.js App Router pages
├── components/ui/                # shadcn/ui (CVA variants)
├── hooks/api/                    # React Query hooks per domain
└── lib/api/                      # Client, endpoints, cache-keys, generated types
```

## Key Rules

- **No useEffect** in frontend — use React Query, useMemo, event handlers.
- **Every route handler** must have `response_model=` and auth via `Depends()`.
- **GET endpoints are read-only** — no side effects (no `ensure_*` or `get_or_create_*`).
- **Query keys** must use factories from `cache-keys.ts` — no raw strings.
- **Types** in `frontend/src/lib/api/types.ts` are auto-generated — never edit.
- **Single dark theme** (Dream11) — no light/dark toggle.
- **Conventional commits** enforced: `feat:`, `fix:`, `refactor:`, etc.
- **No payment gateway** — wallet is a ledger only; settlements tracked but happen offline.
- **Server Components by default** — only use `'use client'` when hooks or interactivity needed.
- **Mobile-first responsive** — design for 375px width first, scale up.

## Design System — Dream11 Clone

Single dark theme, mobile-first, card-based layout.

**Color Palette:**
- Primary Background: `#1A1A2E` (dark navy)
- Secondary Background: `#16213E` (dark blue)
- Card Background: `#0F3460` (blue cards)
- Accent Red: `#E94560` (Dream11 signature red)
- Success Green: `#00C853`
- Warning Yellow: `#FFD600`
- Text Primary: `#FFFFFF`
- Text Secondary: `#9E9E9E`
- Text Muted: `#666666`
- Border: `#2A2A4A`

**Typography:** Inter font family, system-ui fallback. Bold 600-700 for headings.

**UI Patterns:**
- Bottom navigation bar (5 tabs: Home, My Matches, Create Team FAB, Wallet, Profile)
- Card-based layouts with 12px border radius
- Loading skeletons (Tailwind animate-pulse)
- Framer Motion for page transitions

## Environment

Single source of truth: root `.env` file. Frontend `.env.local` is auto-generated by run scripts.

Required: `DATABASE_URL`, `REDIS_URL`, `JWT_SECRET_KEY`, `JWT_ALGORITHM`, `NEXT_PUBLIC_API_URL`.

## Business Rules

- Team: 11 players, 100 credits max, min 1/max 8 per role (WK, BAT, AR, BOWL), min 4/max 7 from each real team
- Captain: 2x points, Vice Captain: 1.5x points
- Scoring: Dream11 T20 rules (1pt/run, 25pt/wicket, economy/SR bonuses, etc.)
- Match locks at `lockTime` — no team edits after
- Contest join deducts entry fee from wallet (or adds to pendingDues)
- Prize distribution creates settlement records for offline payment
- Admin manages everything: tournaments, matches, contests, scores, settlements
